# Abdul Rafay - Cybersecurity Portfolio

A professional portfolio website designed to showcase my skills, certifications, and experience as a Cybersecurity Analyst and Penetration Tester. 

🔗 **Live Demo:** [abdul-rafay-portfolio-omega.vercel.app](https://abdul-rafay-portfolio-omega.vercel.app)

## 🛡️ About Me
I'm a final-year Computer Science student at Capital University of Science & Technology (CUST) with a strong foundation in cybersecurity. My focus areas include penetration testing, vulnerability assessments, SOC analysis, and incident response. 

## ✨ Features
- **Responsive Design:** Fully responsive layout optimized for desktop, tablet, and mobile viewing.
- **Dynamic UI Elements:** Custom cursor, scroll-triggered reveal animations, and smooth parallax effects.
- **Project Filtering:** Interactive tab-based filtering for cybersecurity projects, tools, and scripts.
- **Semantic HTML & Accessibility:** Built with SEO-friendly structured data and focus-visible accessibility standards.
- **Modern Aesthetic:** Carefully selected typography and color palette for a professional, cyber-focused look.

## 🛠️ Technologies Used
- **Frontend:** HTML5, Vanilla CSS3 (Custom Properties, CSS Grid, Flexbox), Vanilla JavaScript
- **Typography:** Plus Jakarta Sans, Source Serif 4, JetBrains Mono
- **Hosting/Deployment:** Vercel

## 📂 Project Structure
```text
├── assets/             # Images, icons, and downloadable resources (e.g. Resume)
├── css/
│   ├── shared.css      # Core variables, typography, and global utility classes
│   └── portfolio.css   # Component-specific styles (hero, projects, experience)
├── js/
│   ├── shared.js       # Global scripts (custom cursor, mobile menu)
│   └── portfolio.js    # Page-specific interactions (animations, project filtering)
├── index.html          # Main HTML document
├── robots.txt          # SEO directives
└── sitemap.xml         # XML sitemap for search engines
```

## 🚀 Local Setup
To run this project locally, you don't need any build tools or package managers. Simply clone the repository and open `index.html` in your browser.

1. Clone the repository:
   ```bash
   git clone https://github.com/abdulrafay-infosec/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio/v1
   ```
3. Open `index.html` in your web browser, or use an extension like VS Code Live Server for hot reloading.
